# Pac-Man

A browser-based Pac-Man game built with HTML, CSS, and JavaScript.

## About the Project

This project is my own implementation of the classic Pac-Man arcade game. Navigate through the maze, collect dots, avoid ghosts, and try to achieve the highest score possible.

The game includes custom visuals, animated Pac-Man movement, ghost behavior, sound effects, and a restart feature.

## Features

- Classic maze-based gameplay
- Dot collection and score tracking
- Ghosts with different movement behaviors
- Multiple lives
- Sound effects and background music
- Win and game-over states
- Restart functionality
- Custom visual styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Web Audio API

## How to Play

1. Open the game in your browser.
2. Use the arrow keys to move Pac-Man through the maze.
3. Collect the dots to increase your score.
4. Avoid the ghosts to protect your remaining lives.
5. Collect all the dots to win the game.
6. Restart the game when needed and try to beat your previous score.

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Moonie-007/Pac-Man.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
